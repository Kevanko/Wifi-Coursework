# Wifi-Coursework

ESP32 Wi-Fi thermostat coursework with a web control panel, sensor integration, and embedded firmware.

## Overview

This project implements an embedded thermostat system on ESP32. It combines firmware, local Wi-Fi access, and a browser-based control panel for device interaction.

## Quick Access

- SSID: `ESP32_THERMO_COURSE`
- Password: `12345678`
- Local URL: `192.168.4.1`

## Structure

- `main` - firmware source code
- `build` - generated build output
- `managed_components` - managed dependencies
- `pytest_onewire.py` - helper/testing script

## Stack

C/C++, ESP-IDF, embedded web UI, Python helper scripts.
